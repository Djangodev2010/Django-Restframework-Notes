
# Django Restframework Practice

This is a repo for showing my journey so far with Django Restframework.



## Run Locally

Clone the project

```bash
  git clone https://github.com/Djangodev2010/Django-Restframework-Notes.git
```

Go to the project directory

```bash
  cd drf_practice
```

Install dependencies

```bash
  pip3 install requirements.txt
```

Migrate the database

```bash
  python3 manage.py makemigrations
  python3 manage.py migrate
```

Start the server

```bash
  python3 manage.py runserver
```
